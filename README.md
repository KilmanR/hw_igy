# Домашнее задание: Iterators, Generators, Yield

Реализация итераторов и генераторов для плоского представления вложенных списков.

## Структура проекта

```
hw_igy/
├── hw_igy.py     # Основные реализации (FlatIterator, flat_generator)
├── test_igy.py   # Тесты (все 4 задания)
└── README.md
```

## Реализовано

1. `FlatIterator` — итератор для списка списков (задание 1)
2. `flat_generator` — генератор для списка списков (задание 2)
3. `FlatIterator` — итератор для списков произвольной вложенности (задание 3*)
4. `flat_generator` — генератор для списков произвольной вложенности (задание 4*)
